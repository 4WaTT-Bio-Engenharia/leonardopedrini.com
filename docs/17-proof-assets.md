## 4. Rotina permanente de geração de prova (para não depender só do passado)

1. **Todo cliente de Mentoria/Sprint** assina, no contrato, cláusula de case: direito de publicar resultados (nomeado ou anonimizado) após validação dos números.
2. **AI Work Lab:** todo Case Review mensal e Demo Day trimestral gera caso escrito com números (doc 09 §5) — meta ≥ 4 casos/mês; os melhores viram posts, artigos e seções de LP.
3. **Padrão mínimo de um case publicável:** setor + porte + baseline medido + resultado medido + período + evidência visual (painel/print) + autorização. Sem um desses itens, não sobe ao site.
4. **Revisão trimestral deste inventário:** mover itens de 📄/⛔ para ✅ conforme documentos chegam; registrar fonte de cada prova.
